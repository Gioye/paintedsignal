Painted Signal

Open Source IPTV Player for custom "Painted Signal JSON Files".


Painted Signal JSON Structure

The JSON format for Painted Signal channels contains the following fields:

  • icon: URL to the channel icon. Can be PNG, ICO, HTTP, or base64.
  • name: Name of the channel.
  • id: Numeric channel ID, used by Painted Signal Discovery.
  • bumper: Media file that plays at the start and end of broadcasts.
  • medialist: Array of media files to play for the channel.

Example

{
  "icon": "https://example.com/icon.png",
  "name": "Sample Channel",
  "id": 1,
  "bumper": "https://example.com/bumper.mp4",
  "medialist": [
    "https://example.com/media1.mp4",
    "https://example.com/media2.mp4"
  ]
}
